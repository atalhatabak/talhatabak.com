{{- /* Overrides themes/blowfish/layouts/partials/language-redirect.html (the theme's JavaScript, assets/js/language-redirect.js, is reused). Only one thing changes: which pages may redirect by browser language. The theme allows either "home page only" or "every page". Here it is "every page of the default language": - An English page opened by a browser that prefers Turkish redirects to the Turkish translation (if there is one). - A Turkish page is never redirected by browser language, so a Turkish link shared with someone using an English browser stays Turkish. - A language chosen from the language menu is stored and always wins (storedLanguageRedirect), in both directions.
